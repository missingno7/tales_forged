# assets/

Original Disney's DuckTales: The Quest for Gold Amiga disk images. The
copyrighted ADF files are local inputs and are not committed. Their exact
filenames, sizes, and SHA-256 identities are pinned in
[../game.json](../game.json).

Both standard 901,120-byte DD images are required. Disk 1 is the boot and
program volume `DT1`; Disk 2 is the companion data volume `DT2`. Keep the
filenames from `game.json` unchanged so `scripts/play.py` can verify and mount
them deterministically.
